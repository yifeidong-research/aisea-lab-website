# AI-SEA Lab Website — Product Context

## Why This Project Exists
Public-facing academic site for the newly-established AI-SEA Lab (AI Systems Engineering &
Assurance Lab) at UTS Data Science Institute, for researchers, students and industry partners —
to advertise the lab's mission, recruit PhD/HDR students, and showcase people/publications/
projects once UTS clears it for public hosting.

## Pages (all under `src/pages/`)
| Page | File | Purpose |
|---|---|---|
| Home | `index.astro` | Hero (mission, UTS Data Science Institute photo background), flagship programme, research themes summary |
| Research | `research.astro` | Aim/approach/partnership paragraphs, research-cycle diagram, research areas list, 3 detailed themes, recruitment contact box |
| People | `people.astro` | Grouped by `category` ("Core Members", "Collaborators", "PhD Students", "Master of Research Students"); photo, name, title+affiliation, bio |
| Publications | `publications.astro` | Sorted by year desc; title links to DOI |
| Projects | `projects.astro` | Flagship programme detail + programme topics; individual projects still placeholder |
| Contact | `contact.astro` | Affiliation, faculty, address (Level 12, Building 2, UTS), public email (mailto) |
| 404 | `404.astro` | Custom not-found page |

## Key files
- `src/content/site.ts` — **single source of truth** for all content (lab info including
  physical `address`, research themes/areas, programme topics, recruitment contact,
  `people`/`publications`/`projects` arrays, `contactEmail`). Edit this file for any content
  change.
- `src/layouts/Base.astro` — shared `<head>`, header nav, footer; imports `global.css` + fonts.
- `src/components/Brand.astro` — wordmark + "Lab" tag (no logo image; UTS logo use needs
  separate authorisation, not yet sought).
- `src/components/PageIntro.astro` — shared page `<h1>` + lead paragraph.
- `src/styles/global.css` — all styling (see `systemPatterns.md` for the design-direction
  decision).
- `public/people/*.jpg` — profile photos (downloaded from UTS profile `/thumbnail` endpoints or
  external lab sites where provided by the user).
- `public/images/uts-central.jpg` — home page hero background photo (UTS Central, Building 2;
  CC BY-SA 4.0, Wikimedia Commons, photo by Robertsky, credited on-page via `.hero-credit`). See
  `systemPatterns.md` for sourcing/licensing and the grayscale+gradient-overlay treatment applied
  via CSS. (Superseded an earlier CC0 Dr Chau Chak Wing Building photo, `uts-campus.jpg`, removed
  per user's follow-up request for this specific UTS Central photo instead.)
- `public/images/research-cycle.png` — Research page diagram (minimal black-ink line-art showing
  the three research themes as a continuous cycle), AI-generated by the user from a Cline-authored
  prompt (see `systemPatterns.md`), resized from 1448×1086 to 1200×900 with `sips` for web
  delivery. Rendered via `.research-row`/`.research-figure` in `research.astro`, embedded beside
  (to the right of) the `lab.aim` paragraph in a two-column row — not a full-width banner (see
  `systemPatterns.md` for the layout revision rationale).
- `public/staticwebapp.config.json` — Azure SWA routing/headers config (404 rewrite, CSP,
  `X-Robots-Tag: noindex` — remove noindex only once ready for real search indexing).
- `scripts/verify-deployment.mjs` — post-deploy smoke test (checks all 6 pages + 404 respond
  with expected `<h1>` text); run automatically by `.gitlab-ci.yml`'s `deploy_azure` job.
